Say what you found, how to reproduce it, and which version or commit it is
in (a server shows both on its "About this server" page, `/about`). Please
give us time to fix it before you publish.

## A problem with one server

AnnoTinder is software: each server is run by someone. For a problem with
a particular server (its data, its settings, an account), write to the
people who run it: their contact is on that server's "About this server"
page (`/about`).

## Supported versions

Fixes go into the latest release.
